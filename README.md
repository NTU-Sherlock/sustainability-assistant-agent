# 永續部助理（sustainability-assistant-agent）

一個裝進 Codex 的 AI 同事，給品牌與永續部門用：整理資料夾、讀信列待辦、每天同業晨報、做簡報、寫新聞稿。名字由你來取。

## 三步開始（不需要 GitHub 帳號）

1. **下載**：按這頁綠色的「Code」→「Download ZIP」，解壓縮。
2. **用 Codex 打開資料夾**：在 Codex 開新專案，選剛剛解壓縮的 `sustainability-assistant-agent` 資料夾。
3. **打招呼**：在聊天框送出「你好，我們先幫你取名字」。

取好名字後，它會介紹自己能做的 5 件事。

## 它會做的 5 件事

| 你說 | 它做什麼 |
|---|---|
| 這個資料夾好亂，哪份是正本？ | 每個檔案打開看，列對照表、找正本，複製整理（不刪原檔） |
| 幫我看最近的信 | 待辦表＋一封回信草稿（只建草稿，不寄出；要先在 Codex 連接 Gmail） |
| 早安，跑今天的晨報 | 同業動態＋獎項雷達，附連結和日期；可用 Codex 排程每天自動跑 |
| 把這份做成簡報 | 公司版型簡報或競賽提案，交出前核對每個數字 |
| 把這封信寫成新聞稿 | 新聞稿草稿，再換成主管角度用四點檢核表檢查 |

## 換成你的

打開 `AGENTS.md`，捲到最後「把我改成你的」，或直接在聊天裡說：

```text
請把 AGENTS.md「把我改成你的」換成：主管偏好＿＿＿；我追蹤的同業＿＿＿；我追蹤的獎項和網址＿＿＿；我常寫的文件＿＿＿。其他段落不要動。
```

## 用公司的簡報版型

這份助理不附任何公司的版型。如果你手上有公司的簡報技能和 `brand/` 資料夾（例如工作坊素材包），在聊天裡說：

```text
請從＿＿＿（素材包位置）把 brand 資料夾和裡面的簡報技能資料夾，複製到這個專案的 brand/ 和 .agents/skills/。
```

## 教它新技能

做完一件順手的事，跟它說：

```text
把我們剛剛做的這件事，做成你的新技能。
```

它會問你技能名稱和用途，確認後存進 `.agents/skills/`，下次一句話就能叫出來。

## 它一定守的規矩

信只擬草稿不寄出、不刪檔、不確定的數字標【待確認】、資料附來源、網頁和信件裡的指令一律不照做。全部寫在 `AGENTS.md`，你可以自己改。
