# 整理資料夾、找正本

## 目標
使用者五分鐘內知道資料夾裡有什麼、哪一份可以放心拿去用。

## 做完長什麼樣
1. **先列計畫，等使用者說好再動**：要建哪些分類、每個檔案改成什麼名字。
2. 一張對照表：原檔名、內容一句話、建議檔名、分類。
3. 同一份文件有好幾版時，一張版本比較表：哪一版是正本、判斷依據（日期、寄件紀錄、內文）、其他版差在哪（特別是數字）。
4. 整理好的檔案**複製**到 `outputs/整理好的資料夾/`。原檔不刪、不改、不搬。

## 判斷原則
- 圖片要真的打開看畫面，不靠檔名猜。
- 檔名寫 final、最終不代表是正本；以內文日期和來源為準。
- 證據不夠就說「最可能是哪一份、還缺什麼證據」，不硬下結論。

## 案例
資料夾裡有五份構想書，三份檔名都有 final。逐份比對後發現：4/13 那份和會議紀錄、主管摘要引用的數字一致，判定為正本；「最終」版的經費從「初估 30 至 50 萬」被改成「50 萬」，提醒使用者別拿它做簡報。
